## Mechanical inference amendment before test reveal

The first execution was stopped during source-validation trajectory-band generation, before any
source-test or external outcome was computed. The fitted histogram residual comparator was calling
the public sklearn `predict()` interface once per node and second; repeated input checking and
OpenMP setup made the frozen sequential rollout unnecessarily slow.

The implementation was mechanically replaced by a numeric-tree single-row traversal that evaluates
the exact already-fitted tree nodes and leaf values. No tree, coefficient, feature, loss proxy,
hyperparameter, threshold, profile, prefix, horizon, or endpoint changed. Unit tests compared 50
random predictions with the public sklearn interface at absolute tolerance `1e-14`. A subsequent
full 1,200-second source trajectory differed by at most `1.4211e-14` °C. The validation-only
selection repeated exactly (alpha 100, penalty 0.1) before the test reveal resumed.

## Frozen outcomes

The direct raw-unit source thermal network achieved 1.8673 °C matched-horizon profile-macro RMSE on
the source test but 24.4928 °C on the external machine, a 13.1167-fold degradation. Its narrow
source-calibrated bands jointly covered only 1 of 16 external profiles.

The source-prior prefix method produced three deliberately unedited gate outcomes:

- source adaptation: failed; relative improvement -51.47%, paired improvement interval lower bound
  -15.6420 °C;
- external adaptation against the frozen normalized source model: passed arithmetically; relative
  improvement 38.09%, paired improvement interval lower bound 0.1296 °C;
- source trajectory coverage: passed; minimum node-wise coverage 13/14 = 92.86%.

The external pass is not interpreted as deployment success. The proposed method's full external
RMSE was 13.6104 °C, worse than five-minute target-only fitting (6.0175 °C), boundary persistence
(6.1664 °C), and the published target-specific LPTN reference (3.4676 °C). It activated the frozen
temperature guard 999 times on external profile 14. The coverage band was also very wide: mean
half-width 106.07 °C across nodes.

The predeclared support rule rejected 10 of 16 external profiles, including profile 14. On the six
supported profiles, source-prior calibration had 3.1933 °C mean RMSE versus 4.5655 °C for target-only
prefix fitting; on the ten unsupported profiles it had 19.8607 °C. These supported-subset numbers
are secondary and cannot replace the all-profile primary outcome or conceal the 62.5% abstention
rate.

## Post-reveal diagnostics boundary

`scripts/analyze_paper4_transport_diagnostics.py` only reshapes frozen profile-level outputs. It does
not refit, retune, rescale, rethreshold, exclude a primary profile, or change a gate. Correlations,
support-stratified errors, and leave-one-profile-out influence descriptions generated by this script
are explicitly post-reveal diagnostics.
