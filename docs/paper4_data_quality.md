# Paper 4 electrothermal data-quality audit

## Decision

The two public datasets are usable for a protocol-frozen, two-machine transport stress test after a
strict three-node harmonization. They are not sufficient for a fleet-generalization claim. The main
data-integrity checks pass; the material risks are semantic transport, an external duration
discrepancy, and leakage from published estimate columns.

## Dataset and grain summary

| Dataset | Grain | Rows | Profiles | Physical machines | Native rate | Audited duration |
|---|---:|---:|---:|---:|---:|---:|
| 52 kW source PMSM | one synchronous sample within one drive profile | 1,330,816 | 69 | 1 | 2 Hz | 184.836 h |
| External IPMSM | one synchronous sample within one profile | 97,725 | 16 | 1 | 1 Hz from published `tsim=1` | 27.146 h |

Profiles are contiguous and appear exactly once in both sources. The candidate key is
`(dataset, profile_id, within-profile row index)`. Neither dataset contains an explicit timestamp;
elapsed time is reconstructed from published sampling information and row order.

## Checks and findings

| Finding | Evidence | Severity | Impact and treatment |
|---|---|---|---|
| Completeness and finiteness pass | Zero null or non-finite values in all required columns | Low risk, high confidence | No imputation is permitted or needed |
| Exact-row uniqueness passes | Zero exact duplicate rows in both raw sources | Low risk, high confidence | Profile ordering can be preserved directly |
| External aggregate is lossless | All 97,725 raw rows in `temperature.csv` agree exactly with the 16 `id_*.csv` files for the 22 raw columns | Low risk, high confidence | Raw `id_*.csv` files remain the authoritative modeling input |
| Published estimates create leakage risk | `temperature.csv` adds `active_wind_est`, `stator_est`, and `rotor_est`, generated by the authors' target-specific LPTN | Critical if mishandled, high confidence | These columns are blocked from all primary preprocessing, fitting, tuning, and evaluation |
| External duration metadata disagree | README says 23.8 h; 97,725 rows at the repository's `tsim=1` imply 27.146 h | Medium, high confidence | Report both; use rows and code-defined step for all calculations |
| No explicit timestamps | Time is implied by 2 Hz publication metadata and external `tsim=1` code | Medium, high confidence | Never infer dropped-sample gaps; analyze ordered fixed-step sequences only |
| Thermal-node semantics are not identical | Source PM is mapped to external rotor; both stator-core nodes are constructed averages | High, high confidence | Call this a semantic bridge/proxy and report each node separately |
| Severe machine/domain shift is real | Source speed reaches 6000 rpm and winding 141.36 °C; external reaches 4036.69 rpm and winding mean 65.40 °C | High, high confidence | Use an explicit support score; retain unsupported profiles in primary results |
| Machine-level replication is absent | One physical machine in each dataset | Critical for broad inference, high confidence | Bootstrap profiles only and condition all conclusions on the two machines |

## Distribution facts relevant to modeling

The source contains 69 profiles lasting 18.13--366.43 min (median 142.85 min). The external set
contains 16 profiles lasting 25.60--220.60 min (median 90.54 min). Consequently, a five-minute
prefix plus a common 20-minute evaluation horizon is available for every locked test profile.

Selected full-range contrasts are:

| Variable | Source range | External range |
|---|---:|---:|
| Ambient | 8.78--30.71 °C | 17.90--27.90 °C |
| Coolant / water outlet | 10.62--101.60 °C | 19.22--26.70 °C |
| Speed | -275.55--6000.02 rpm | 0--4036.69 rpm |
| Torque | -246.47--261.01 N m | -61.38--158.28 N m |
| Winding target | 18.59--141.36 °C | 18.77--65.40 °C |
| Rotor/PM target | 20.86--113.61 °C | 18.82--77.90 °C |

Ranges establish compatibility, not accuracy. They were inspected before model fitting and cannot
be used later to choose a winning method or redefine the test subset.

## Automated controls

The audit pipeline enforces required schemas, finite numeric values, exact-row uniqueness,
contiguous profile storage, raw-to-aggregate equality, exclusion of estimate columns, immutable
hashes, a one-to-one profile manifest, and deterministic 2 Hz-to-1 Hz source reduction. These checks
are stable and suitable for automated regression tests.

## Assumptions and claim boundary

Speed and torque are treated as rpm and N m according to their source documentation/code naming.
The external repository's MIT license is treated as applying to the included data files. Any journal
submission should cite both dataset sources and preserve their attribution/license notices.

The evidence supports: “transport between these two recorded PMSMs under the frozen protocol.” It
does not support: “generalizes across arbitrary PMSM fleets, power classes, cooling systems, or
temperature-sensor placements.”
